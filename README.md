# Student Result Management System (Version 2)

A Python and SQLite-based Student Result Management System developed to efficiently manage student academic records through a Command Line Interface (CLI). The system provides separate **Admin** and **Student** portals, enabling secure record management and instant result generation.

---

## Project Overview

The Student Result Management System (SRMS) is designed to simplify the process of storing, updating, retrieving, and displaying student academic information. It uses **SQLite** as the backend database and follows a **modular Python architecture**, making the project organized, reusable, and easy to maintain.

---

## Features

### Admin Portal

* Password-protected access
* Add new student records
* Search students using Hall Ticket Number
* Display all student records
* Update student information and marks
* Delete student records

### Student Portal

* View student result using Hall Ticket Number
* Automatic grade calculation
* Pass/Fail status for each subject
* SGPA calculation
* Percentage calculation
* Total marks calculation
* Well-formatted result sheet
